# GNR8 MVP Supported Site Classes

MVP-1 canonical supported-site-class matrix for the first approximately 200-site operator-assisted migration wave.

Classification values:

- Supported for MVP
- Supported with manual review
- Importable but not launch-ready
- Out of scope for MVP
- Future/post-MVP

## Site-Class Launch Rules

| Rule | MVP requirement |
| --- | --- |
| Static-first | A site is launch-eligible only if its public user experience can be served by static/raw-template/runtime artifacts plus approved content overrides. |
| Dynamic behavior | Dynamic features must be externalized, manually verified, or classified out of scope. |
| Forms | No form launches without end-to-end submission evidence or an approved replacement path. |
| Commerce/payment/auth | Not part of MVP launch. Public marketing pages may be imported for review only. |
| External scripts/widgets | Must be classified as non-critical, preserved and verified, or replaced with approved static/runtime component. |
| SEO/redirects | Complex redirect history requires manual review and launch approval. |
| Domain cutover | Custom domain launch requires Vercel/domain verification or explicit manual DNS exception. |
| Rollback | Every launched site must have a rollback target or documented DNS/source recovery plan. |
