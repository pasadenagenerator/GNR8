# GNR8 Domain DNS Operator Workflow

DDOM-1 operator workflow for MVP domain and DNS operations.

This is documentation and product architecture only. It does not implement UI, APIs, DNS behavior, Vercel behavior, provider behavior, approvals, audit, publish, rollback, or Command Center/Ops Inbox changes.

## Product Guardrails

- Never show "DNS complete" unless GNR8 has acceptable evidence or check result.
- Never show "domain ready" without a freshness label.
- Never show "publish allowed" from domain readiness alone.
- Never show "Openprovider ready" as write authority.
- Never offer live DNS mutation in MVP.
- Never let AI produce a domain action without human approval and future ADR.
- Always show whether DNS action belongs to GNR8, Vercel, registrar, client, account manager, or external provider.

## Operator Roles

| Role | Domain responsibility | Must not do in MVP |
| --- | --- | --- |
| Technical operator | Domain readiness checks, Vercel snapshot review, internal host/runtime triage, incident recovery recommendation. | Live DNS/registrar mutation through GNR8 or Openprovider live write. |
| Account manager | Client DNS owner discovery, instruction sharing, external follow-up refs. | Treat external email/ticket as GNR8 approval. |
| Client/account owner | Perform DNS changes in external provider when they control DNS. | Mutate GNR8 runtime/publish state. |
| Superadmin | Critical exceptions, cross-client domain conflicts, future ADR enforcement. | Hidden provider/DNS mutation. |
| AI advisory reviewer | Future checklist review only. | Execute or approve domain actions. |

| Handling publish blocked by domain state | Resolve domain blocker before publish. | Publish readiness failed item. | Missing/stale/failed domain dependency, owner, allowed actions. | Domain action or exception evidence. | Regenerate, collect evidence, recheck, defer, exception. | Publish anyway without exception and publish approval. | Domain approval plus publish approval if exception used. | `publish.readiness_failed`. | Prohibited publish reason. | `publish_readiness_failed`, `domain_action_needed`. | Domain gate resolved. | Domain blocker unresolved. |

| Handling rollback when domain/cutover issue occurs | Restore service or route safely. | Incident/recovery view. | Runtime rollback target, domain state, external DNS rollback owner. | `rollback_evidence` plus domain incident refs. | Execute GNR8 runtime rollback if approved; request external DNS revert. | Claim GNR8 changed external DNS back. | `rollback`; external action needs owner/refs. | `rollback.requested`, `rollback.succeeded`, external ref events. | Runtime rollback and external DNS steps separated. | `rollback_needed`, `external_workflow_update`. | Runtime verified and external DNS plan recorded. | External DNS still points incorrectly. |
| Preserving external registrar/provider reference | Keep external context without owning it. | External reference view. | URL/id/provider, capturedAt, owner, linked subject. | `external_workflow_reference_evidence`. | Link, refresh, accept as evidence, unlink. | Treat as GNR8 truth/approval. | Acceptance if used to unblock. | `external_ref.linked`, `external_ref.accepted_as_evidence`. | External snapshot label. | `external_workflow_update`. | Reference current enough for use. | Snapshot stale/unavailable. |

| Escalating to technical operator/superadmin/client/account owner | Route domain blockers to accountable human. | Ops Inbox item. | Severity, owner role, blocker, evidence refs, prohibited actions. | Scope-specific package if decision needed. | Assign/escalate/request approval/follow-up. | Close item without source/audit. | Depends on escalation action. | `domain.escalated` or approval/external events. | Owner and severity. | Domain item remains open until resolved. | Owner accepts next action. | No owner or critical conflict. |

## UI Language Requirements

- Use "DNS instructions generated" instead of "DNS complete" until evidence/check supports completion.
- Use "Vercel check ready" instead of "DNS ready" when only Vercel state is known.
- Use "Domain prerequisite satisfied" instead of "publish allowed".
- Use "Openprovider inventory snapshot" instead of "Openprovider ready".
- Use "External DNS owner action required" when the action is outside GNR8.
