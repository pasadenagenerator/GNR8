1. Purpose

Migration Factory je:

deterministični sistem za pretvorbo obstoječih spletnih strani v GNR8 runtime.

To NI:
	•	site scraper
	•	pixel-perfect cloner
	•	visual builder

To JE:

👉 industrialized website onboarding pipeline

⸻

2. Core Mission

Cilj migration factory v V1:
	•	omogočiti agencijam masovni prehod obstoječih strank v GNR8
	•	zmanjšati migration risk
	•	omogočiti AI-driven izboljšave po migraciji

To pomeni:

Migration ≠ final product
Migration = bootstrap into AI lifecycle

⸻

3. Migration Philosophy

GNR8 migration model je:

Best-effort semantic reconstruction

Ne:
	•	pixel cloning
	•	DOM replay
	•	visual diff perfection

Ampak:
	•	content capture
	•	layout intent reconstruction
	•	brand signal extraction
	•	asset preservation
	•	structural normalization

⸻

4. Migration Factory High-Level Flow

Input URL / Site
 → Snapshot ingestion
 → Asset discovery & capture
 → Semantic parsing
 → Layout reconstruction
 → Brand inference
 → Static preview generation
 → Operator validation
 → Approval
 → GNR8 runtime activation
 → AI improvement lifecycle

To je:

👉 canonical onboarding pipeline

⸻

5. Migration Input Contract

V1 mora podpirati:

Supported inputs
	•	single-page sites
	•	simple multi-page brochure sites
	•	CMS sites (rendered HTML)
	•	builder-based static outputs

Not supported (V1)
	•	complex authenticated apps
	•	heavy SPA logic reconstruction
	•	backend business logic migration
	•	ecommerce logic migration

⸻

6. Snapshot Model

Snapshot mora biti:
	•	deterministic
	•	versioned
	•	reproducible
	•	immutable

Snapshot vključuje:
	•	HTML
	•	CSS
	•	images
	•	fonts
	•	basic JS
	•	metadata

Ne vključuje:
	•	server logic
	•	dynamic DB calls
	•	user flows

⸻

7. Asset Strategy

Assets morajo:
	•	biti lokalizirani
	•	deduplicirani
	•	fingerprinted
	•	CDN-ready

Asset types:
	•	images
	•	stylesheets
	•	fonts
	•	media

Asset fidelity target:

👉 visual identity preservation

Not:

👉 runtime parity

⸻

8. Semantic Extraction Layer

Migration mora ustvariti:

Page Semantic Model
	•	sections
	•	content blocks
	•	hierarchy
	•	navigation intent
	•	CTA signals
	•	brand tone signals

To je:

👉 input za AI system

⸻

9. Layout Reconstruction Model

Layout reconstruction:
	•	container/grid inference
	•	spacing approximation
	•	typography mapping
	•	section intent mapping

Target:

recognisable layout, not identical layout

⸻

10. Brand Inference Layer

System mora iz migracije inferirat:
	•	primary colors
	•	typography system
	•	imagery style
	•	tone of voice
	•	positioning hints

To postane:

👉 brand seed model

⸻

11. Preview Generation

Preview mora biti:
	•	static
	•	fast
	•	deterministic
	•	CDN-serving capable

Preview je:

👉 validation artifact

Not:

👉 production runtime

⸻

12. Operator Validation Model

Operator mora videti:
	•	layout fidelity
	•	content completeness
	•	asset integrity
	•	brand match
	•	critical errors
	•	migration warnings

Operator lahko:
	•	approve
	•	reject
	•	request rerun
	•	adjust parameters

⸻

13. Approval Gate Philosophy

Migration activation:
	•	nikoli fully automatic v V1
	•	vedno operator-gated

Activation pomeni:

👉 site postane GNR8-managed entity

⸻

14. Post-Migration Lifecycle

Po aktivaciji:

Migration complete
 → AI semantic analysis
 → Improvement proposals

Migration je:

	•	produce diagnostics
	•	allow reruns
	•	allow partial success

No silent failures.
