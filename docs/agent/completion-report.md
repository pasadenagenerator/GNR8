# GNR8 Completion Report

Use this concise format at the end of a Codex task.

```text
Summary:
-

Files changed:
-

Validation:
- Command/result:
- Evidence:

Product behavior changed:
- No, unless explicitly stated.

Quality gates:
- Scope respected:
- Contracts preserved:
- Tests/checks appropriate to risk:
- No hidden execution/provider/DNS mutation:

Residual risks / follow-ups:
-
```

Keep the report short. Link files when the client supports it; otherwise list exact paths.

For integration tasks, add only the applicable evidence: current decision checklist satisfied or exceptions; exact artifact/input and deployed revision; local versus hosted validation; cumulative hosted attempts if the loop-control checkpoint was reached. Distinguish technical pass from visual acceptance, merge, and publication. Do not call an unapproved omission an accepted limitation or promise that the next deployment is the last.
