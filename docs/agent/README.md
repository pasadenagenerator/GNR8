# GNR8 Agent Docs

These files keep the root `AGENTS.md` small and move detailed guidance behind a router.

- `context-router.md`: choose the minimum project context for the task.
- `workflow-policy.md`: token-budget workflow, exploration limits, tool policy, subagents, and handoffs.
- `model-routing.md`: model and reasoning defaults plus escalation rules.
- `validation-policy.md`: focused testing and full-check boundaries.
- `completion-report.md`: short completion format.

Do not preload all files by default. Open only the files needed for the current task.
