# GNR8 Domain DNS Readiness And Evidence Model

DDOM-1 readiness, stale-status, and evidence model for MVP domain and DNS operations.

This is documentation-only. It defines future implementation requirements without changing behavior.

## Readiness Principles

- Domain readiness is a derived publish prerequisite, not publish approval.
- DNS instructions are snapshots, not proof of completion.
- Vercel checks are snapshots, not registrar/DNS truth.
- External registrar/DNS providers remain authoritative for external DNS and registrar truth.
- GNR8 stores operating records, evidence refs, snapshots, approvals, audit refs, and readiness projections.
- Stale domain evidence must not enable publish without explicit domain exception and separate publish activation approval.

## Evidence Objects

| Evidence object | What it proves | What it does not prove | Freshness/staleness rule | Source-of-truth relationship | Required refs | Privacy/redaction concerns | Replay/recheck behavior |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Intended domain record | GNR8 captured a desired launch domain for a site/client. | Ownership, DNS correctness, Vercel readiness, publish approval. | Stale when site/client/domain/launch plan changes. | GNR8 operating truth for intent; external DNS truth separate. | site, client, domain, actor, timestamp. | Avoid private owner/contact data unless needed. | Correct by new audited record. |
| Domain owner note | GNR8 recorded who likely controls DNS. | That the owner still has access or completed changes. | Stale when owner/ref changes or confirmation window expires. | GNR8 note/evidence; external owner remains source. | owner role/ref, registrar/provider hint, timestamp. | Redact credentials, account emails when client unsafe. | Refresh by manual confirmation. |
| DNS instruction snapshot | Instructions shown for manual DNS work. | DNS mutation, DNS completion, provider truth. | Stale when provider/state/policy/timestamp/domain/binding changes. | GNR8 computed snapshot from policy/Vercel/inferred refs. | instruction id, records, basis refs, generatedAt. | Record values are safe to show only to authorized owner. | Regenerate as new snapshot; never overwrite evidence. |
| DNS completion evidence | Human/external evidence that DNS owner acted. | Full DNS truth unless verified by provider/check. | Stale unless followed by fresh check or recent confirmation. | GNR8 evidence ref; DNS provider truth external. | actor, owner, external ref/screenshot/note, instruction ref. | Redact registrar account data and unrelated records. | Recheck Vercel/DNS; capture new evidence if changed. |
| Vercel check snapshot | Vercel reported domain/project status and records at a time. | Registrar ownership, nameservers, whole zone truth, publish approval. | Stale when TTL expires or domain/binding changes. | Vercel authoritative for its own status; GNR8 stores snapshot. | check id, binding id, status, records, lastCheckedAt. | Avoid provider tokens/errors with secrets. | Re-run as new check with environmental variance. |
| SSL/readiness snapshot | SSL/runtime readiness dependency was checked at a time. | Permanent readiness or publish approval. | Stale by TTL or domain/runtime changes. | Vercel/runtime check snapshot. | readiness id, domain, result, timestamp, errors. | Redact certificates/private diagnostics if needed. | Recheck as new snapshot. |
| Domain exception evidence | Approver accepted a domain blocker under scope. | DNS mutation, external truth, publish approval. | Stale when scope, launch window, domain/check/owner changes. | GNR8 approval/evidence truth for exception only. | approval ref, evidence package, limitations, expiry. | Client-visible risk language may be redacted by surface. | New exception needed after supersession. |
| External registrar reference | Link/snapshot to registrar/DNS external state. | GNR8 truth or approval. | Stale unless freshly captured or manually confirmed. | External registrar remains authoritative. | external system/ref/url, capturedAt, owner, subject. | Redact account ids, nameservers for client-safe views if needed. | Re-capture or confirm; do not replay. |
| Openprovider/provider inventory snapshot | Read-only provider inventory at a time. | Write authority or current provider truth after time passes. | Stale by provider snapshot policy or provider/source change. | Provider remains authoritative; GNR8 stores snapshot. | provider id, inventory ref, fetchedAt, diagnostics. | Redact tokens, account handles, unrelated domains. | Re-read as new snapshot; live mutation forbidden. |
| Audit timeline refs | Events and decisions linked to domain work. | Missing event families or source truth if timeline partial. | Partial/stale when event source unavailable or superseded. | Audit is append-only/federated event truth. | event ids, correlation ids, action refs. | Redact actor/client data by surface. | Not replayed; append compensating events for gaps. |

## Stale Rules

- DNS instructions stale when provider/state/policy/timestamp changes.
- Vercel check stale when TTL expires or binding/domain changes.
- External registrar snapshot stale unless freshly captured or manually confirmed.
- Openprovider/provider inventory stale when provider read window expires or provider config changes.
- Domain owner evidence stale when owner/contact/delegation changes or confirmation expires.
- Domain readiness stale when any dependency changes.
- Approval/evidence packages stale when referenced domain, instruction, check, owner, runtime, publish, rollback, incident, cost, or policy refs change.
- Stale domain evidence must not enable publish without explicit exception and publish approval.

## Readiness Summary

`domain_ready` means the domain prerequisite is currently acceptable for the named launch path. It never means DNS is permanently correct, publish is approved, rollback is ready, or external registrar/DNS truth has moved into GNR8.
