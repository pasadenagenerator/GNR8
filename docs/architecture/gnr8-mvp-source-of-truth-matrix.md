# GNR8 MVP Source-Of-Truth Matrix

MVP-1 canonical source-of-truth matrix for the first operator-assisted migration and website operations MVP.

This matrix uses explicit source-of-truth values:

- canonical
- projection
- derived
- immutable artifact
- append-only event
- transient
- external system of record
- review-only
- presentation-only
- forbidden as source of truth

## MVP Source-Of-Truth Rules

1. Runtime serving authority comes from active pointer/site version/runtime artifact/published override state, not from generated proposal bundles, thumbnails, WU/VCU, DBT, AI plans, or UI projections.
2. Command Center and Ops Inbox read from canonical stores and derived projections; neither may silently write source-of-truth state except through approved domain services.
3. External systems remain their own source of truth in MVP: DNS registrars, Stripe, CRMs/project tools, CMS backends, commerce platforms, booking systems, and auth providers.
4. Any domain with write authority that is currently "TBD" must be resolved before implementation touches that workflow.
5. AI/provider outputs are never source of truth in MVP. They are review-only artifacts until accepted by a human and converted through approved deterministic workflow.
