# GNR8 MVP Source-Of-Truth Matrix

MVP-1 canonical source-of-truth matrix for the operator-assisted migration and website operations MVP.

This document is documentation-only. It does not authorize schema, API, runtime, publish, rollback, DNS/domain, billing, provider, thumbnail, Generated Proposal Bundle, Workspace, Evolution, or AI execution changes.

## Required Assertions

- Runtime truth must be active pointer, site version, runtime artifact, and published override state.
- Review projections are not production truth.
- Thumbnails are presentation artifacts and must remain immutable/private review artifacts.
- Generated Proposal Bundles are durable proposal artifacts, not active public runtime truth unless explicitly promoted through approved publish flow.
- AI/provider outputs are immutable evidence bundles or advisory artifacts, not automatic production truth.
- External systems remain source of truth for their own records unless GNR8 explicitly adopts that domain through an approved architecture decision.

## Non-Authoritative Artifacts And Projections

The following are non-authoritative for production runtime in MVP: Command Center read models, Ops Inbox work items, preview URLs, Website Understanding, Source Content and Visual Continuity, Website Version Thumbnails, Knowledge Workspace, Generation Evolution, Generated Proposal Bundles, Digital Business Twin artifacts, Website Design Briefs, Website Generation Packages, provider payloads, AI outputs, screenshots used only for presentation, DNS instruction views after they become stale, billing dashboards, and external workflow snapshots.

They may support review, audit, triage, planning, or approval, but they do not serve public traffic and do not mutate production truth.

## MVP Rules

1. Runtime serving authority is active pointer, site version, runtime artifact, and published override state.
2. Review projections are read-only review inputs. They can support an approval package but cannot independently authorize publish.
3. Thumbnails, Generated Proposal Bundles, Knowledge Workspace, and Generation Evolution are not production runtime truth.
4. AI/provider outputs must be captured as immutable advisory/evidence bundles before any operator uses them; they cannot mutate runtime, approvals, billing, domains, provider state, or external workflows in MVP.
5. External systems remain authoritative for their own domains. GNR8 stores associations, snapshots, instructions, evidence, and audit unless an approved ADR changes ownership.
6. Any source-of-truth row with TBD persistence, such as approval state, incident/recovery events, external workflow references, or replay input bundles, must be resolved before implementation uses it as a write path.
