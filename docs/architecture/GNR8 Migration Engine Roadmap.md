# GNR8 Migration Engine Roadmap

Status: CORE EXECUTION DOCUMENT

---

# 1. Mission

GNR8 must become:

> The most accurate deterministic website migration engine in the world.

This roadmap defines:

- capability evolution
- execution order
- risk layering
- fidelity unlock milestones
- founder decision checkpoints

This roadmap explicitly assumes:

Migration comes BEFORE AI generation.

---

# 2. Migration Engine Evolution Model

Migration capability evolves through **five phases**:

1. Raw Import Engine
2. Structural Reconstruction Engine
3. Semantic Reconstruction Engine
4. Visual Intent Reconstruction Engine
5. AI Remediation Layer

Each phase must reach production stability before the next.

---

# 3. Phase 1 — Raw Import Engine

### Goal

Make migration reliable, not beautiful.

### Capabilities

- deterministic HTML snapshot ingestion
- asset harvesting
- link graph capture
- DOM preservation
- source normalization
- multi-page crawl integrity
- content hashing
- snapshot reproducibility
- importer stability guarantees

### Success Criteria

- Migration never fails technically
- Any site can be imported
- Snapshot fidelity is deterministic

### Migration Level Unlocked

L1 (Raw fallback migration)

### Maver Status

Phase mostly complete.

---

# 4. Phase 2 — Structural Reconstruction Engine

### Goal

Rebuild layout structure correctly.

### Capabilities

- DOM → Layout Graph conversion
- section boundary detection
- layout region inference (hero / body / footer)
- gallery grouping
- nav isolation
- form detection
- multi-column inference
- layout rhythm detection
- breakpoint pattern detection

### Key Principle

Structure reconstruction must be deterministic first.

### Success Criteria

- Section ordering matches original
- Layout hierarchy preserved
- Page recognizability emerges

### Migration Level Unlocked

L2 → L3

### Maver Status

Partially achieved (S3)

This is the current battlefield.

---

# 5. Phase 3 — Semantic Reconstruction Engine

### Goal

Understand business meaning.

### Capabilities

- hero intent detection
- services clustering
- contact extraction
- CTA detection
- legal vs content classification
- navigation vs content disambiguation
- multilingual content interpretation
- business-type heuristics
- section role labeling

### Critical Constraint

Semantic engine must not hallucinate.

It must remain evidence-based.

### Success Criteria

- Hero correct
- Contact correct
- Services correct
- Legal removed from hero

### Migration Level Unlocked

L3 → L4

### Maver Status

Currently M2.5 → must reach M3+

---

# 6. Phase 4 — Visual Intent Reconstruction Engine

### Goal

Reconstruct visual design intent, not CSS.

### Capabilities

- layout density modeling
- spacing rhythm inference
- visual hierarchy reconstruction
- typography scale inference
- color palette extraction
- grid reconstruction
- hero proportion inference
- gallery layout reconstruction
- responsive behavior inference

### Key Philosophy

We do NOT replay CSS.

We reconstruct design intent.

### Success Criteria

- Page feels visually similar
- Layout rhythm matches
- Visual identity preserved

### Migration Level Unlocked

L4

### Maver Status

Currently V2.5

This is next major unlock.

---

# 7. Phase 5 — AI Remediation Layer

### Goal

Fix what deterministic engine cannot.

### Capabilities

- layout correction suggestions
- semantic corrections
- visual refinement
- missing asset reconstruction
- CTA optimization
- content restructuring
- section splitting/merging
- brand tone alignment

### Critical Rule

AI does not replace migration engine.

AI improves migration engine output.

### Success Criteria

- Migration + AI output > original site quality
- Migration time dramatically reduced
- Manual redesign not required

### Migration Level Unlocked

L5

---
