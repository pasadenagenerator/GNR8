# GNR8 Domain And DNS MVP Boundary

DDOM-1 exact MVP boundary for domain and DNS handling.

This is documentation-only. It does not implement domain or DNS behavior.

## Boundary Statement

MVP domain/DNS work is operator-assisted coordination. GNR8 may record intent, show manual instructions, store snapshots/evidence, request supported Vercel checks, and derive readiness. GNR8 must not be treated as registrar, DNS provider, autonomous DNS repair agent, Openprovider live operator, or publish approver.

| Live DNS record mutation | Forbidden | MVP is manual DNS only; no live provider write governance. | External DNS provider. | Future ADR plus `domain_action`/provider-specific approval. | `dns.record_mutation_attempted`, `dns.record_mutation_succeeded/failed`. | Disabled/prohibited with reason. | `domain_action_needed` for manual owner work. | Wrong record can break live site/email. |

| Domain purchase | Forbidden | Purchase is commercial/legal/provider write action. | Registrar/provider. | Future ADR, cost/legal/client approval. | `domain.purchase_attempted`. | Future-only label if shown. | `external_workflow_update`. | Unauthorized spend/ownership. |
| Domain transfer | Forbidden | Transfer can disrupt ownership and DNS. | Registrar(s). | Future ADR, client/legal/superadmin approval. | `domain.transfer_attempted`. | Future-only label if shown. | `external_workflow_update`. | Downtime or domain loss. |
| Nameserver mutation | Forbidden | Nameserver changes can move entire DNS authority. | Registrar/DNS owner. | Future ADR, superadmin/client approval. | `nameserver.mutation_attempted`. | Not offered. | External follow-up only. | Email/site outage. |
| Openprovider live write execution | Forbidden | Existing Openprovider code is read-only or sandbox diagnostic; live writes need ADR. | Openprovider. | Future Openprovider ADR and provider approval. | `provider.openprovider.live_write_attempted`. | Read-only inventory with live blocked warning. | `provider.live_blocked`, `domain_action_needed`. | Overclaiming provider readiness. |
| Automatic DNS repair | Forbidden | Autonomous repair would mutate external records. | DNS owner/provider. | Future ADR plus incident/domain approval. | `dns.repair_attempted`. | Prohibited action reason. | `domain_action_needed`. | Silent destructive repair. |
| Autonomous domain cutover | Forbidden | Cutover is client-visible launch side effect. | GNR8 publish plus external DNS owner; separate truths. | Future ADR, launch, domain, publish approvals. | `domain.cutover_attempted`. | Manual checklist only. | `approval_needed`, `domain_action_needed`. | Unapproved launch/downtime. |
| AI-driven DNS/domain changes | Forbidden | AI is advisory only. | Human approval and external owner remain authoritative. | Future AI/domain ADR plus human approval. | `ai.domain_action_proposed`, human action event. | Advisory review only. | `ai_plan_review`. | Autonomous outage. |
| Treating external provider page/screenshots as GNR8 truth | Forbidden | Screenshots are staleable evidence only. | External provider remains truth. | External ref acceptance if used as evidence. | `external_ref.accepted_as_evidence`. | External snapshot label. | `external_workflow_update`. | Stale screenshot unblocks publish. |
| Treating DNS instruction display as completion | Forbidden | Display does not mutate DNS. | DNS provider/check/evidence. | Domain exception only if accepted without check. | `dns.instructions_shown`, not completion. | Instruction shown separately from completion status. | `domain_action_needed`. | False readiness. |
| Treating Vercel check as registrar/DNS truth | Forbidden | Vercel knows its project/domain state, not entire registrar/DNS source. | Vercel only for Vercel state. | Domain exception if relying despite external uncertainty. | `dns.check_completed` with external snapshot label. | Vercel snapshot label. | `dns_verification_failed` or stale item. | Missing upstream nameserver/zone issue. |

## Boundary Rules

1. Domain readiness cannot create launch approval or publish approval.
2. Domain action approval cannot approve publish activation.
3. Domain exception approval cannot approve DNS mutation.
4. Vercel snapshots cannot become registrar/DNS truth.
5. Manual DNS instructions cannot become completion proof without evidence or fresh check.
6. Provider inventory cannot become live provider write authorization.
7. Command Center and Ops Inbox can show and route work, but cannot own source truth.
